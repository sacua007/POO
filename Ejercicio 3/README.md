# Proyecto Mascota 

Este es un programa simple en Python que usa **Programación Orientada a Objetos (POO)** para crear mascotas y mostrar información sobre ellas.

## Descripción

El programa crea una clase llamada `Mascota`.
Cada mascota tiene:

* nombre
* tipo de animal
* color

También puede realizar una acción como ladrar o ronronear.

## Cómo funciona

1. Se crea la clase `Mascota`.
2. Se define un constructor (`__init__`) para guardar los datos.
3. Se crean métodos para mostrar información y acciones.
4. Se crean dos mascotas de ejemplo.
