Implementación de Clases Abstractas en Python 🐾
Este proyecto es un ejemplo sencillo pero potente sobre el uso del módulo abc (Abstract Base Classes) en Python. Demuestra cómo definir una interfaz común para diferentes objetos utilizando el concepto de Abstracción.

🚀 ¿Qué es esto?
El código define una estructura jerárquica donde una clase base (la "plantilla") obliga a sus clases hijas a implementar comportamientos específicos.

Conceptos clave aplicados:
Clase Abstracta (Animal): Una clase que no se puede instanciar directamente y sirve como molde.

Método Abstracto (@abstractmethod): Un método definido en la clase base que debe ser sobrescrito por cualquier subclase.

Polimorfismo: La capacidad de tratar a diferentes objetos (Perro y Gato) de la misma manera a través del método común hablar().
