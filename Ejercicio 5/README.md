# Sistema de Personajes en Python

Este proyecto implementa un sistema básico de personajes utilizando Programación Orientada a Objetos (POO) en Python.

Se crea una clase base llamada **Personaje** y varias clases que heredan de ella, como **Guerrero**, **Mago** y **Arquero**, cada una con su propia habilidad especial.


## Conceptos utilizados

Este proyecto usa conceptos de Programación Orientada a Objetos:

- Clases
- Herencia
- Constructores (__init__)
- Métodos
- Sobreescritura de métodos

## Autor
